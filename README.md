## 🌟 핵심 특징 (Key Highlights)

### 1. 🍷 웅장한 하이엔드 다크 와인 디자인 시스템 (Luxury Dark Wine Theme)
- 보르도/버건디 와인 래디얼 그라데이션과 골드 아키텍처 그리드가 결합된 웅장한 Hero 대문
- 로즈 골드 테두리 배지 및 샴페인 골드 에디토리얼 타이포그래피 적용
- 다크 글래스모피즘(Dark Glassmorphism) 기반 실시간 스펙 패스포트 카드

### 2. 📐 정밀 2D 도면 & 3D 렌더 인터랙티브 뷰어
- 4대 국가표준 실시도면(평면도, 천장조명배선도, 전개도, 상세도) SVG 벡터 실시간 뷰어
- 3D 하이퍼리얼 렌더링 및 2D 도면 간 부드러운 크로스페이드(Cross-fade) 전환
- 공간별 디테일 및 마감재 스펙 시트 실시간 탐색

### 3. 📄 1장 완결형 입사지원서 & 자기소개서 스마트 인쇄 시스템 (Print-Engine)
- **입사지원서**: 인적사항, 학력, 7종 국가자격, 12종 소프트웨어 역량, 프로젝트 실적을 **A4 딱 1장에 꽉 찬 전문가 표준 표 양식**으로 완결
- **자기소개서**: 지능형 스마트 패킹(Smart-Capacity Packing) 알고리즘을 적용하여, **빈 공간 낭비 없이 4개 문항 전체를 A4 정갈한 1장에 꽉 채워 완결** (글자 수 대폭 초과 시에만 1장을 먼저 채우고 2장으로 분할)
- 브라우저 인쇄 시 웹 요소(헤더, 푸터, 버튼 등) 100% 자동 소멸 및 백지 0장 방어

### 4. 📱 360px 모바일 완벽 반응형 (Mobile First)
- 모바일 초소형 뷰포트(360x780)부터 데스크톱 4K 해상도까지 수평 스크롤 오버플로우 0건
- 한글 단어 단위 자동 줄바꿈(`word-break: keep-all`)으로 텍스트 가독성 극대화

## 🚀 GitHub Pages 1분 무료 웹 배포 방법

본 포트폴리오는 외부 백엔드나 복잡한 빌드 과정 없이, 순수 웹 표준(HTML5/CSS3/Vanilla JS)으로 제작되어 **GitHub Pages를 통해 클릭 몇 번으로 즉시 전 세계에 무료 배포**할 수 있습니다.

1. 본 저장소 상단의 **`Settings`** (설정) 탭을 클릭합니다.
2. 좌측 메뉴에서 **`Pages`** 메뉴를 클릭합니다.
3. **Build and deployment** 항목의 **Branch** 설정을 `None`에서 **`main`** (또는 `master`)으로 변경하고, 우측 폴더는 **`/(root)`** 상태로 둔 뒤 **`Save`**를 누릅니다.
4. 약 1~2분 후 새로고침하면 상단에 **나만의 공식 웹사이트 주소**가 생성됩니다!
   > 🌐 **접속 주소 예시**: `https://<깃허브아이디>.github.io/<저장소이름>/`
